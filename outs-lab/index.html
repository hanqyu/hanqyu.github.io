실전 카드로 아웃츠 훈련

홀 카드와 보드를 읽고 아웃츠와 2·4 법칙 확률을 직접 입력해봐. 정답 카드도 바로 확인할 수 있어.

문제 #1플랍 → 리버
목표: 플러시난이도: 기본
내 핸드
커뮤니티 카드

상대 핸드가 아니라 내 드로우 완성 기준으로 계산해.

훈련 기록
아웃츠 정답 0 / 0확률 정답 0 / 0연속 완벽 정답 0

건너뛰기는 점수에 반영하지 않아. 확률 정답은 2·4 법칙 기준 ±2%p까지 인정해. 표시하는 정밀 확률은 현재의 아웃츠가 적어도 한 장 등장할 확률이야. 턴에서 새로운 드로우가 생기는 러너러너 완성 확률은 포함하지 않아. 아웃츠는 상대 핸드에 따른 역전 가능성(더티 아웃츠)을 고려하지 않은 드로우 완성 기준이야.
